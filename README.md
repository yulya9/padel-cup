# Padel Cup: анимированный лендинг

Статичный прототип без сборки: HTML, CSS, JS. Сайт на английском, десктоп от 1440 px (на узких экранах простая стековая вёрстка).
Макет в Figma: страница **Padel Landing** в файле «Для собесов».

Открыть: двойной клик по `index.html` (шрифты Geist и DM Mono подтягиваются с Google Fonts, нужен интернет).

## Анимации (по образцу theperformancelab.ca, без GSAP)
- **Lenis** плавный скролл, один цикл `requestAnimationFrame`, одна кривая `cubic-bezier(.16, 1, .3, 1)`.
- **Прелоадер** со счётчиком 000–100 и мячом, шторка поднимается, hero проявляется из чёрного.
- **Hero**: заголовок выезжает построчно из маски, фото чуть сжимается и уезжает при скролле.
- **Бегущие строки** (партнёры и неоновая лента): дрейф `0.5 px × направление − 0.6 × дельта скролла`, направление меняется вместе со скроллом.
- **Шапка** прячется при скролле вниз и возвращается при скролле вверх, после hero становится светлой.
- **Коллаж-интро**: окна `overflow: hidden` с контр-параллаксом (окно и картинка внутри едут в разные стороны), проявление фото через `clip-path`.
- **Scrub-текст**: слова закрашиваются из серого в чёрный по скроллу.
- **Заголовки** появляются по буквам, **числа** считаются при входе в экран.
- **Огромные подписи** («Crew», «Schedule») выезжают справа: `translate3d((1 − t) × 720px)`, прозрачность 0.15 → 1.
- **Карточки шагов** появляются по очереди, кнопки магнитные, FAQ-аккордеон на `height`.
- **Фон «траектория мяча»**: пунктирная линия с отскоками рисуется по скроллу, мяч едет по ней, в точках отскока появляются кольца.
- **Поп-ап**: открытие/закрытие, валидация (имя, email или телефон), выбор уровня, экран успеха с рисованием галочки, Esc, фокус-ловушка.
- `prefers-reduced-motion`: всё показывается сразу, без Lenis.

## Палитра (проверка APCA, порог для текста Lc 60)
Светлая тема: `#F2F2F2` фон, `#171717` текст, `#666666` второстепенный, `#D0D0D0` обводка, акцент чёрный `#171717`.
Тёмная тема: `#171717` фон, `#F2F2F2` текст, `#BBBBBB` второстепенный, `#4A4A4A` обводка, акцент неон `#A8EB33` (приглушён), текст на нём `#141414`.
Чистые `#000000` и `#FFFFFF` не используются.

| Пара | Lc |
|---|---|
| `#171717` на `#F2F2F2` | 97 |
| `#666666` на `#F2F2F2` / `#FFFFFF` / `#EBEBEB` | 71 / 79 / 67 |
| `#F5F5F5` на `#171717` (кнопка) | 100 |
| `#C42B15` на `#FFFFFF` (ошибка) | 77 |
| `#F2F2F2` на `#171717` | 98 |
| `#BBBBBB` на `#171717` / `#1F1F1F` / `#272727` | 65 / 64 / 62 |
| `#A8EB33` на `#171717` (неон как текст) | 82 |
| `#141414` на `#A8EB33` (кнопка) | 82 |
| `#FF9A8A` на `#1F1F1F` (ошибка в поп-апе) | 61 |
| `#171717` на `#F2F2F2` при 0.8 (названия партнёров) | 85 |

Осознанно ниже порога: серые «призрачные» слова фразы до прокрутки (промежуточное состояние эффекта, после скролла Lc 97), гигантские фоновые подписи и линия траектории мяча (декор).
